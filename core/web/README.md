# 统一前端（第 3 步）

由 v1 数据包生成各卷新页面 `docs/<短名>/index.html`。规范第十九节迁移第 3 步的产物。

```
python core/web/assemble.py             八卷全部（须先有 build/v1/，即 python run.py --v1）
python core/web/assemble.py songyuan    只做这几卷
python run.py --web                     全局表、v1 数据、新页面一起重建
```

| 文件 | 内容 |
| --- | --- |
| `assemble.py` | v1 → 旧格式数据 → 套进新模板，写出 `docs/<短名>/index.html`；生成深链接用的标识 |
| `patch.py` | 把各卷旧模板（`eras/<短名>/src/template.html`）改成新模板：换时间轴、接深链接、统一语言键与播放倍速、加安全区、源码链接指向本仓库；春秋、战国的疆域不透明度与唐宋系一致（.5 / .66）。`patch_geo` 是第 4 步加的：统一投影与接缝、全球底图与海岸线画法、地形晕渲图层、图例「地形」开关，参数取自 [`core/geo/config.toml`](../geo/config.toml)，说明见 [`core/geo/README.md`](../geo/README.md) |
| `shell.js` | 共用脚本：时间轴、深链接、界面语言 |
| `shell.css` | 共用样式：时间轴、播放倍速、刘海屏安全区 |

各卷的地图绘制逻辑原样沿用旧模板。第 3 步验收时逐卷比对过，新旧页面的地图、索引、年表、对照表逐项相同，差别只在时间轴、深链接与第 3 步的改正（`core/v1/overlay.py`）；第 4 步换了投影、加了全球底图与地形晕渲，地图的样子从此与旧版不同。第 5—7 步改为由 v1 直接推算疆域、八卷共用一个模板后，`patch.py` 退役。

## 时间轴

上面一条按真实年代比例的细条：每个节点一道刻线，当前节点加粗，方框标出下面刻度当前露出的那一段；点细条跳到最近的节点。下面是等宽刻度，每格：年份（按月的卷为 `年·月`）/ 短标题 / 年号（春秋、战国无年号）。短标题：战国式写在各卷源文件，唐宋系写在 `eras/<短名>/short.tsv`。

## 深链接

地址栏 `#` 后记下当前状态，复制即可分享；页面里每次操作都用 `history.replaceState` 更新，不产生浏览记录。打开页面后没动过就不写，地址保持干净。

| 参数 | 含义 | 例 |
| --- | --- | --- |
| `y` | 时间节点：年份，按月的卷写 `年.月`；不是节点时取其后最近的节点 | `y=1127`，`y=1937.12`，`y=-260` |
| `sel` | 选中的对象，按全局 ID：`polity:`政权、`place:`地点、`<类别>:`条目（全局 ID 或古名；同卷重名加 `@所属政权` 或 `@年份`） | `sel=polity:金`，`sel=place:长安`，`sel=battle:城濮之战` |
| `v` | 视野（与默认相同时不写） | `v=hb` |
| `c` | 着色方式（与默认相同时不写） | `c=zhen` |
| `z` | 缩放与中心：相对所选视野的倍数 / 经度 / 纬度（与视野一致时不写） | `z=2.4/116.40/39.90` |
| `lang` | 界面语言，中文不写 | `lang=en` |

`polity:` 与 `place:` 用全局 ID，跨卷通用：`#sel=place:长安` 在哪一卷都指长安。旧链接的 `#en`、`#zh` 照常有效。界面语言另存于浏览器（`lidai-yutu:lang`，与首页共用；没有时沿用各卷旧版存的设置）。
