# 统一前端

由 v1 数据包生成各卷新页面 `docs/<短名>/index.html`。规范第十九节迁移第 3 步起的产物。

```
python core/web/assemble.py             各卷全部（须先有 build/v1/，即 python run.py --v1）
python core/web/assemble.py songyuan    只做这几卷
python run.py --web                     全局表、v1 数据、新页面一起重建
```

| 文件 | 内容 |
| --- | --- |
| `template.html` | 统一模板：九卷共用（春秋、战国 2026-11-25 起）。图层按数据有无出现；各卷不同的文字与少数开关写在 `eras/<短名>/era.toml` 的 `[web]` 一节（见下） |
| `assemble.py` | v1 → 旧格式数据 → 套进模板，写出 `docs/<短名>/index.html`；填 `[web]` 的文字与开关、投影参数与晕渲浓淡（取自 [`core/geo/config.toml`](../geo/config.toml)）、共用外壳；生成深链接用的标识 |
| `simple.py` | 春秋、战国两卷：`legacy.from_v1` 转回的是战国式写法（简单模型），由它再转成模板读的唐宋系写法：诸侯国、部族为单位，名城要邑、一般城邑为州府（`t` 为 z / t），事件 culture 改名 event，长城、驰道并入 road，秦郡、共主依据照带；深链接另认两卷旧版的标识（`city:`、`town:`、`culture:` 等写法） |
| `falls.py` | 各卷灭国表 `eras/<短名>/content/falls.tsv` → 页面的 `DATA.falls`（年份换成本卷的时间值，单位名换成序号，逐行校验）；见下「灭国表」 |
| `shell.js` | 共用脚本：时间轴、深链接、界面语言 |
| `shell.css` | 共用样式：时间轴、播放与步进、倍速、刘海屏安全区 |

## 统一模板与 `[web]`

七卷原来各有一份模板（相互差两三百到五百多行），2026-11 合成 `template.html` 一份；春秋、战国两卷原用战国式旧模板（由已删去的 `patch.py` 换上共用外壳），2026-11-25 也改用这一份，九卷共用。合并时逐卷逐项比对：新旧页面在同一串操作下（逐个节点、两种着色、各视野、缩放、点索引各组、图例开关、地图悬停与点击、检索、键盘、年表、对照表、英文、深链接、深色、窄屏）DOM 相同，几种状态下的截图逐像素相同，差别只在合并时有意统一的少数写法（逐条列在当次的对照页与提交说明里）。比对 DOM 看不出图层的上下次序和样式表，这两样另外核对过。

各卷的差别分三类：

- **图层**：有数据就画，不设开关。州界郡界（`zb`/`zl`）、海名、线状地物（铁路、公路、古道、长城、航线）、租界、重要地域、运河开凿年份、河道改道等，没有这类数据的卷自然不出现。
- **文字**：标题、视野、图例与脚注、着色按钮、计数与说明里的称呼、索引分组名、对照表与年表的导语等，写在 `[web]`，中英各一份。
- **开关**：只有各卷含义确实不同的才设，如 `time`（时间单位：年、年月、月序号、秦汉的通鉴纪年）、`hatch`（斜线在哪种着色下画）、`vassal`（斜线单位当藩属另画轮廓与名称）、`lines_under_canal`（长城、驰道画在运河之下：秦汉，免得鸿沟被驰道盖住）；春秋、战国另有 `cmodes`（只有一种着色时不出着色按钮：战国）、`hatch = "pol"`（斜线只在政权着色下画：春秋奉周）、`zhen_flat`（二级单位着色下各国一律按政权画：春秋「诸侯」着色）、`pref_zoom`（名城出现的倍数）、`road_chron`（修长城、驰道进年表）、`cm_alias`（旧链接的着色代号）。索引分组名如 `road_group`（长城、驰道、古道一组的名称，与图例开关同名；组内依次为长城和塞、驰道直道、古道栈道）；年表都城一行的政权名可按都城另写，如宋元的 `cap_st`（1271 年建号大元以前，开平、中都记在大蒙古国名下）。说法类的项也在 `[web]`，如 `pol_word`、`pol_group`、`town_group`、`vassal_tag`、`overlord_word`（斜线单位在说明里的种类与「宗主」的说法：春秋写「国」「共主」），`seat_word` 可写一个词（只改中文）或 `[中, 英, 英「… of」]`（春秋、战国：都 / capital）。

`[web]` 每一项的含义写在各卷 `era.toml` 里该项上面的注释。改文字只动 `era.toml`，不用碰模板；加一卷时照现有各卷填一份，缺的项用模板里的缺省值。

## 时间轴

左栏自上而下是播放 ▶、步进 ‹ ›、倍速 1×。‹ › 与键盘 ← → 同效（停止播放、走一个节点），到第一个或最后一个节点变灰；2026-11 第六批随战国式时间条去掉，同月第七批起九卷都有。

上面一条按真实年代比例的细条：每个节点一道刻线，当前节点加粗，方框标出下面刻度当前露出的那一段；点细条跳到最近的节点。下面是等宽刻度，每格：年份（按月的卷为 `年·月`；秦汉卷按通鉴纪年，太初以前十至十二月记在下一年，细条上的位置仍按真实先后）/ 短标题 / 年号（春秋、战国无年号）。短标题：春秋、战国写在各卷源文件，其余各卷写在 `eras/<短名>/short.tsv`。

## 灭国表

九卷同一写法：`eras/<短名>/content/falls.tsv`，制表符分隔，一行一条，列为 `年份 键 方式 标题 经过 年表 title_en text_en`（说明见 [`falls.py`](falls.py) 开头）。

- **年份**：`前205·10`、`约前180`、`622`、`1945·8`；秦汉按本卷通鉴纪年写（同节点标签）。
- **键**：地图上的单位名，一字不差；一条涉及几国用「、」隔开（如「霍、古魏、耿」）。找不到或有重名，构建即停。
- **方式**：灭、篡、废、亡、分裂、降、内属、臣服、并。只影响年表的类别：降、内属、臣服、并而标题不以「亡」收尾的记「归附」，「亡」记「败亡」（割据者败死、为部下所杀等），其余记「灭国」。
- **标题**：年表里的标题，用当期图例上的名字（如汉末写「吴巨死」，不写数据里的单位名「刘表」）。
- **年表**：年表里已有讲同一件事的事件（如「东北易帜」「曹丕受禅」）写「否」，这一条只用来划图例。

页面上：图例里上一节点在、这一节点不在、表里又有它的国，灰字划掉、色块变淡，悬停显示标题与年份；点它停在这一节点，地图移到它原来的位置。每一条配到地图上这一国消失的节点（上一节点在、这一节点不在，取与年份最近的一次；亡年恰在上一节点的算上一期；相差 15 年以上的不配，免得配到同一单位别的时候消失）；按政权着色与按二级单位着色各配一次，所以秦汉、汉末这类二级单位也列在图例里的卷，两种着色下划掉的不全一样。年表收「年表」为「是」的各条，点击同样跳到这一国消失的节点（按当前着色配的）。地图本身不受影响。英文两列不能空；中英写在同一行，改中文时顺手改英文（这张表不进各卷的指纹检查）。

哪些写进表、哪些不写：只写这一期真正结束的独立政权（被灭、投降、篡代、内乱而亡、被废、整体内属或臣服、分裂而终）；改名改号、只是暂时没画或暂失地盘、占位的分组名、举族迁走、正常交接、同一政权分合、殖民地易手、年代只能估到几十年的，一律不写。逐条的判断见规范第八节。

## 深链接

地址栏 `#` 后记下当前状态，复制即可分享；页面里每次操作都用 `history.replaceState` 更新，不产生浏览记录。打开页面后没动过就不写，地址保持干净。

| 参数 | 含义 | 例 |
| --- | --- | --- |
| `y` | 时间节点：年份，按月的卷写 `年.月`（秦汉卷写纪年年.月）；不是节点时取其后最近的节点 | `y=1127`，`y=1937.12`，`y=-260`，`y=-206.2` |
| `sel` | 选中的对象，按全局 ID：`polity:`政权、`place:`地点、`<类别>:`条目（全局 ID 或古名；同卷重名加 `@所属政权` 或 `@年份`） | `sel=polity:金`，`sel=place:长安`，`sel=battle:城濮之战` |
| `v` | 视野（与默认相同时不写） | `v=hb` |
| `c` | 着色方式（与默认相同时不写） | `c=zhen` |
| `z` | 缩放与中心：相对所选视野的倍数 / 经度 / 纬度（与视野一致时不写） | `z=2.4/116.40/39.90` |
| `lang` | 界面语言，中文不写 | `lang=en` |

`polity:` 与 `place:` 用全局 ID，跨卷通用：`#sel=place:长安` 在哪一卷都指长安。旧链接的 `#en`、`#zh` 照常有效。界面语言另存于浏览器（`lidai-yutu:lang`，与首页共用；没有时沿用各卷旧版存的设置）。
