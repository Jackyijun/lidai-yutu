# 统一前端

由 v1 数据包生成各卷新页面 `docs/<短名>/index.html`。规范第十九节迁移第 3 步起的产物。

```
python core/web/assemble.py             各卷全部（须先有 build/v1/，即 python run.py --v1）
python core/web/assemble.py songyuan    只做这几卷
python run.py --web                     全局表、v1 数据、新页面一起重建
```

| 文件 | 内容 |
| --- | --- |
| `template.html` | 统一模板：秦汉、汉末三国、两晋南北朝、隋唐、唐宋、宋元、民国七卷共用。图层按数据有无出现；各卷不同的文字与少数开关写在 `eras/<短名>/era.toml` 的 `[web]` 一节（见下） |
| `assemble.py` | v1 → 旧格式数据 → 套进模板，写出 `docs/<短名>/index.html`；填 `[web]` 的文字与开关、投影参数；生成深链接用的标识 |
| `patch.py` | 春秋、战国两卷还用战国式旧模板（`old/<短名>.html`，原是两卷的 `src/template.html`，2026-11 架构整理第三批移到这里），由它换上共用外壳：时间轴、深链接、语言键、安全区、源码链接，以及第 4 步的统一投影、全球底图、地形晕渲（`patch_geo`，参数取自 [`core/geo/config.toml`](../geo/config.toml)）。两卷改用统一模板后退役 |
| `shell.js` | 共用脚本：时间轴、深链接、界面语言 |
| `shell.css` | 共用样式：时间轴、播放倍速、刘海屏安全区 |

## 统一模板与 `[web]`

七卷原来各有一份模板（相互差两三百到五百多行），2026-11 合成 `template.html` 一份。合并时逐卷逐项比对：新旧页面在同一串操作下（逐个节点、两种着色、各视野、缩放、点索引各组、图例开关、地图悬停与点击、检索、键盘、年表、对照表、英文、深链接、深色、窄屏）DOM 相同，几种状态下的截图逐像素相同，差别只在合并时有意统一的少数写法（逐条列在当次的对照页与提交说明里）。比对 DOM 看不出图层的上下次序和样式表，这两样另外核对过。

各卷的差别分三类：

- **图层**：有数据就画，不设开关。州界郡界（`zb`/`zl`）、海名、线状地物（铁路、公路、古道、长城、航线）、租界、重要地域、运河开凿年份、河道改道等，没有这类数据的卷自然不出现。
- **文字**：标题、视野、图例与脚注、着色按钮、计数与说明里的称呼、索引分组名、对照表与年表的导语等，写在 `[web]`，中英各一份。
- **开关**：只有各卷含义确实不同的才设，如 `time`（时间单位：年、年月、月序号、秦汉的通鉴纪年）、`hatch`（斜线在哪种着色下画）、`vassal`（斜线单位当藩属另画轮廓与名称）、`oldcap_pref`（旧都处照画当时的州府点：唐宋、隋唐、两晋）、`lines_under_canal`（长城、驰道画在运河之下：秦汉，免得鸿沟被驰道盖住）。

`[web]` 每一项的含义写在各卷 `era.toml` 里该项上面的注释。改文字只动 `era.toml`，不用碰模板；加一卷时照现有各卷填一份，缺的项用模板里的缺省值。

## 时间轴

上面一条按真实年代比例的细条：每个节点一道刻线，当前节点加粗，方框标出下面刻度当前露出的那一段；点细条跳到最近的节点。下面是等宽刻度，每格：年份（按月的卷为 `年·月`；秦汉卷按通鉴纪年，太初以前十至十二月记在下一年，细条上的位置仍按真实先后）/ 短标题 / 年号（春秋、战国无年号）。短标题：战国式写在各卷源文件，唐宋系写在 `eras/<短名>/short.tsv`。

## 深链接

地址栏 `#` 后记下当前状态，复制即可分享；页面里每次操作都用 `history.replaceState` 更新，不产生浏览记录。打开页面后没动过就不写，地址保持干净。

| 参数 | 含义 | 例 |
| --- | --- | --- |
| `y` | 时间节点：年份，按月的卷写 `年.月`（秦汉卷写纪年年.月）；不是节点时取其后最近的节点 | `y=1127`，`y=1937.12`，`y=-260`，`y=-206.2` |
| `sel` | 选中的对象，按全局 ID：`polity:`政权、`place:`地点、`<类别>:`条目（全局 ID 或古名；同卷重名加 `@所属政权` 或 `@年份`） | `sel=polity:金`，`sel=place:长安`，`sel=battle:城濮之战` |
| `v` | 视野（与默认相同时不写） | `v=hb` |
| `c` | 着色方式（与默认相同时不写） | `c=zhen` |
| `z` | 缩放与中心：相对所选视野的倍数 / 经度 / 纬度（与视野一致时不写） | `z=2.4/116.40/39.90` |
| `lang` | 界面语言，中文不写 | `lang=en` |

`polity:` 与 `place:` 用全局 ID，跨卷通用：`#sel=place:长安` 在哪一卷都指长安。旧链接的 `#en`、`#zh` 照常有效。界面语言另存于浏览器（`lidai-yutu:lang`，与首页共用；没有时沿用各卷旧版存的设置）。
