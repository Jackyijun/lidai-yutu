# core/geo：统一投影、全球底图、地形晕渲（规范第十九节第 4 步）

八卷共用的参数都在 [`config.toml`](config.toml)，改一处八卷都生效。

| 要改的 | 改哪里 | 然后运行 |
| --- | --- | --- |
| 晕渲浓淡（浅色 / 深色） | `[relief]` 的 `opacity_light`、`opacity_dark` | `python run.py --web` |
| 投影、接缝 | `[projection]` | `python run.py --geo` |
| 晕渲分档、灰度换算、压缩质量 | `[relief]`、`[[relief.tier]]` | `python run.py --geo` |
| 全球底图的化简、岛与湖的取舍 | `[world]` | `python run.py --geo` |

`--geo` 重新生成 `geodata/relief/`、`geodata/world/`（入库），接着出新页面；`--web` 只把已有的这两份并进页面，不需要原图，也不需要网络。

## 文件

| 文件 | 作用 |
| --- | --- |
| `config.toml` | 全部参数 |
| `geo.py` | 读配置；统一投影的 Python 实现（与前端 `proj()` 同一组数）；出页面时把晕渲、全球底图并入 GEO，本卷陆地切边加密 |
| `relief.py` | 下载并校验晕渲原图，按档生成各卷的晕渲图 → `geodata/relief/<短名>/` |
| `world.py` | 全球陆地与大湖 → `geodata/world/<短名>.json` |

前端的改动（投影参数、接缝、全球陆地与海岸线的画法、晕渲图层、图例里的「地形」开关、浓淡）由 [`core/web/patch.py`](../web/patch.py) 的 `patch_geo` 注入各卷模板。

## 投影

八卷统一为 Albers 等积圆锥：标准纬线 25°N、47°N，中央经线 105°E，原点纬线 35°N，`SCL = 1000`（1 个 SVG 单位约 6.37 km）。原来各卷各取本图区域中心，统一以后离 105°E 越远的卷转得越多：宋元约 6°，春秋、战国约 4°。

接缝在大西洋 30°W：经度小于 -30° 的一律加 360°。这样美洲排在亚洲东边，只切开格陵兰；代价是离中国越远变形越大，欧洲、非洲被拉宽，美洲侧着排在亚洲右上方。疆域数据都存经纬度、运行时才投影，换投影不用重算疆域。

## 全球底图

- 各卷自己范围以内仍用本卷的 1:10m 陆地；范围以外补上 Natural Earth 1:50m 陆地（化简 0.06°，去掉面积小于 0.04 平方度的岛）和面积大于 1.5 平方度的湖（1:10m），南纬 60° 以南不画。
- 全球陆地向本卷范围里伸进 0.1°，压在本卷陆地下面；两份陆地再各描一道陆地色的细边，拼接处不露缝。
- 海岸线不另存，前端从多边形描出：本卷陆地跳过落在范围边上的切边，全球陆地跳过本卷范围以内的部分，两者都跳过接缝上的切边。
- 本卷陆地被范围切出的直边可长达几十度，出页面时每 0.5° 加一点，投影后贴合曲线。不加点的话，这条边投影后是一根弦，和全球陆地的弧之间会露出一道海（曾在澳大利亚中部出现）。

## 地形晕渲

原图是 Natural Earth 1:10m Shaded Relief（`SR_HR.zip`，等经纬度 1′ 一格的灰度图，约 42 MB），不入库：`relief.py` 第一次运行时下载到 `build/raw/`、校验 sha256，再存一份 `.npy` 备用。网络不通时，手动下载 `config.toml` 里 `source` 那个文件放进 `build/raw/` 即可。

- **分辨率按地区定、不按卷定**：中国本部及周边（东经 70°—140°、北纬 15°—55°）2 km，亚欧大陆 5 km，全球 10 km。每一档在统一投影平面上有一套全局像素格（第 i 列像素中心 x = (i + .5) × 步长），各卷只是从里面取一块，同一个地方在哪一卷都是同样的像素，等于从一张总图里裁剪；第 9 步首页可以直接共用。
- **每卷三张图**：全球一档取全图；亚欧、中国两档只取本卷「全图」范围以内的部分，边上留 1° 透明度渐变，盖在粗档上。粗档里被细档完全盖住的像素改成平地，省体积。
- **灰度换算**：原图平地与水面是 205；阴坡按 0.85 倍压暗、阳坡按 1.6 倍提亮，编成平地 = 128。页面里三张图放进同一个 `<g>`，先普通叠成一张，再整体 `mix-blend-mode: hard-light` 混合到底图上：浅色模式下主要是阴坡压暗，深色模式下主要是阳坡提亮，一张图两种配色都能用。浓淡由 CSS 变量 `--hill-op` 控制，数值来自 `config.toml`。
- **图层位置**：疆域颜色与割据斜线之上，界线、河流、注记之下；只画在陆地上。图例里「地形」可以关掉。
- **体积**：每页增加约 0.45 MB（春秋、战国）到 1.1 MB（民国），加上全球底图 0.07—0.14 MB，都在每页 1.5 MB 的预算内。

## 可复现

晕渲图与全球底图生成一次后入库，出页面只是原样嵌入，所以 `--web`、`--check` 在任何机器上结果都一样，不受 Pillow、shapely 版本影响。重新生成（`--geo`）的结果才与库版本有关，建议用 `requirements-lock.txt` 里的版本。
