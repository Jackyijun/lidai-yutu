# 战国列国形势图

[![中文](https://img.shields.io/badge/lang-%E4%B8%AD%E6%96%87-red.svg)](README.md) [![English](https://img.shields.io/badge/lang-English-blue.svg)](README.en.md)

战国至秦统一后的极盛（前475—前212）的交互历史地图：49 个时间节点的列国疆域，29 国（七雄之外还有周、宋、卫、鲁、中山、越、巴、蜀、苴、义渠，以及战国前期尚存的晋、郑、吴、蔡、杞、莒、邾、滕、薛、郯、随、许）与 3 支戎狄部族，200 多处都城、城邑、关隘的古今地名对照，秦郡的逐步设置，以及战役、事件与工程、长城、驰道直道、山川、周边诸族。界面中英双语，地图右上角「中 | EN」切换。

本图前接[春秋列国形势图](https://jackyijun.github.io/chunqiu-map/)：两图共用同一份归属点和同一张通行代价栅格，春秋末节点（前476）与本图首节点（前475）的疆域、配色逐像素一致。前350 以后的 37 个节点与补入战国前期之前大体相同：退出的点仍是描界的护点，后来又补了几个点（见第五节「`seeds.txt` 语法」），界线略有出入。

本图后接秦汉形势图（2026-11 在单仓里新编，卷三）：秦汉卷首节点前212 照搬本图末节点前212 的秦、卫疆域与秦郡，两图衔接处的疆域、配色一致。

## 三、本地构建

在单仓根目录构建（Python 版本与依赖见单仓 README）：

```bash
python run.py zhanguo  # 本卷第 1 段 → 统一引擎重算疆域（engine.json）→ v1 数据 → docs/zhanguo/index.html
python run.py --web    # 不重算，只由各卷的 source.json、engine.json 重建 v1 数据与新页面
```

本目录的 `run.py` 是第 1 段：由 `content/` 的史料与 `geodata/` 的底图写出 **`source.json`**（节点归属、文字、条目与底图，不含疆域与配色，入库），单仓由它转成 v1 数据。疆域由统一疆域引擎（单仓 `core/engine/`）按各节点的归属推算，结果存在本目录的 `engine.json`（入库）；颜色由单仓 `global/palette.toml` 定；页面由单仓 `core/web/` 生成。本卷原来的疆域推算、配色与页面模板 2026-11 架构整理第三批起退役。

| 命令（本目录） | 作用 |
|---|---|
| `python run.py` | 底图缺失则下载 → 底图与点要素归属（`build/geo.json`）→ 汇编 `source.json` |
| `python run.py --html` | 跳过底图与归属，只重新汇编（只改了 `content/features.py` 里的文字或 `content/en/` 的英文时用） |
| `python run.py --draft` | 英文有缺译或过期时也照样汇编（缺译处临时显示中文），只供预览；不加时构建会停下并列出缺译 |
| `python tools/i18n.py status` | 查英文缺译、过期的条数 |

改了 `content/` 以后，从单仓根目录 `python run.py zhanguo` 重建这一卷（第 1 段、疆域、页面一次做完）。只在本目录跑 `run.py` 不会更新 `engine.json` 和页面；归属变了而疆域没重算时，单仓 `python run.py --web` 发现引擎输入的指纹对不上，会停下。

同一份输入，`source.json` 逐字节一致，可以用 git 追踪改动。

底图数据（`geodata/ne/`）随仓库附带，离线也能构建；文件缺了，`run.py` 会从 GitHub 下载固定版本（Natural Earth v5.1.2）。

页面由单仓九卷共用的统一模板 `core/web/template.html` 出（2026-11-25 起；此前用战国式旧模板）：本卷的 v1 先经 `core/web/simple.py` 转成模板读的写法，本卷不同的文字与开关写在 `era.toml` 的 `[web]`。

## 五、工作原理

> 单仓新页面（`docs/zhanguo/`）的疆域，第 7 步（2026-11-19）起改由统一疆域引擎推算（`core/engine/`，结果在本目录的 `engine.json`，根目录 `python run.py zhanguo` 时自动重算）；归属、文字、条目仍出自本卷，归属点仍是与春秋卷共用的 `content/seeds.txt`。外缘照旧构建的办法（`era.toml` 的 `[engine]` 写 `outer = "box"`）：推算范围同下面的栅格（97°—128.5°E、18°—44.5°N），范围内的陆地都分给最近的点（陆路够不着、离岸较远的岛留白，如台湾），不属任何一方的点占位之处留白；与旧构建不同的是代价按统一引擎的地形算，海不可通行，疆域不再画到海上。秦郡也由引擎出：秦的格子按郡治就近再分一层（`era.toml` 的 `[engine]` 写 `sub.unit`、`sub.hosts`、`sub.seats`；郡治取本卷的秦郡条目，即 `content/features.py` 的 `JUN`；郡治须在秦、卫境内（原先离境不到 4 格也算，为前277 起的洞庭郡而设；2026-11-21 洞庭郡改为前222 置后删去，河东郡也不再在郡治安邑还属魏的前290 提前画出）。原在 `src/jun.py`，2026-11-21 架构整理第五批写进 `era.toml`）；`sub.fixed` 把下辨这个归属点的势力格整块分给陇西郡（下辨是秦陇西郡属县，单按郡治远近会分给汉中郡；2026-11-21 加）。2026-11-19 在 `seeds.txt` 西北补了武威、张掖、阿拉善、居延 4 个无主点，前212 年秦的西北界因此在贺兰山—黄河一线。

```
content/seeds.txt ──┐
content/links.txt ──┤
content/features.py ┼─► build.py ─► build/geo.json ─► assemble.py ─► source.json ─► 单仓 core/：统一引擎疆域、v1、新页面
geodata/ (底图) ────┘                                    ▲
                                    content/features.py + content/en/
```

### 1. 为什么疆域要“算”出来

战国没有现成的边界数据。史书能确定的大多是“某年某城归某国”。所以这里的做法是：

1. 只手写**地点 → 国家**的归属及其变化年份（`seeds.txt`）；
2. 用一张“通行代价”地图让计算机推出国与国之间的分界，让分界尽量落在山脊和大河上。

> 下面讲的疆域推算、配色与页面模板是本卷旧构建的做法，2026-11 架构整理第三批起已从本目录删去（第 1 段只出 `source.json`），留作说明旧版页面怎么来的。第 2 小节里的第 1、6 步（陆地、水系）与最后一步（地点归属）仍是第 1 段的做法。

### 2. 旧构建 `build.py` 的步骤

1. **陆地**：从 Natural Earth 裁出东亚陆地，简化后编码。
2. **代价栅格**：0.05° 一格。陆地代价 1，海 4.5；`features.py` 里每条山脉按其“阻隔权重”加代价，古黄河、济水、易水、北洛水和江、汉、漳也加代价；再叠一层固定随机种子的平滑噪声，让界线略带自然弯曲。这张栅格与春秋图完全相同，原由 `config.py` 的 `COST_SHA` 每次核对。
3. **多源最短路**：从当年参与分区的归属点同时出发做 Dijkstra，每一格归给“走过去最近”的那个点。前350 以前，除了带 `^`、还没到起始年的点，全部的点都参与（按现在的 `seeds.txt` 共 491 个，其中雍氏前473 起参与，下辨、高阙和四个护点前350 以后才参与），前350 起只用不带 `~` 标记的 397 个点（下辨前280 起，高阙和四个护点前214 起，见下节）；点集相同的节点只算一次。
4. **逐节点着色**：对每个时间节点，按 `seeds.txt` 查出每个点当年属哪国，把格子合并成各国范围，高斯平滑后描出轮廓并简化。注记位置取每国最大一块陆地的内部最远点。
5. **秦郡**：对每个节点，取当时已经设置、且郡治在秦境内的郡，以各郡治为源点在同一张代价图上再做一次多源最短路，把秦境划分给各郡，描出郡界。郡界因此只是“就近归郡”的推算，不是史载的郡界。
6. **水系与湖泽**：Natural Earth 河流按英文名对到古名；战国黄河故道、济水、北洛水、伊洛、汝颍、泗水、滹沱、易水等手绘补上。今黄河下游另画一条虚线以示古今改道。
7. **地点归属**：每个城邑、关隘、战役点（还有郡治）落在哪个归属点，写在 `content/links.txt`，带上那个点的归属变化，供提示框显示“某年属某国”。原先是查点落在哪个归属点的格子里；架构整理第三批（2026-11-20）起旧的分区格子不再参与，各点所落的归属点按当时查得的结果冻结在这张表里，新加的点要在表里写上（构建时检查）。2026-11-21 把按统一引擎的分区会落到别的归属点的 7 条逐条对过史料，改了其中 2 条（李悝变法的点在安邑，原落在陕；中牟前350 起改落朝歌），说明写在文件开头。

### 3. `seeds.txt` 语法

每行一个点：

```
名称 经度 纬度 初始归属 [年份归属 ...] [^年份] [~年份]
```

- `·` 表示不属任何诸侯国（戎狄蛮夷之地）；部族也有自己的键（如 `白狄`、`西戎`）。
- 年份用负数表示公元前，`-330秦` 表示前330 年起属秦。
- `~-350` 表示这个点从前350 起不再参与分区：为春秋小国、戎狄和战国前期补的点都带这个标记。此后参与分区的是原战国图的点，加上 2026-11 补的西北 4 个无主点、前280 起的下辨、前473 起的雍氏，以及前214 起的高阙与四个护点；退出的点所在的格子仍是描界时的护点，前350 以后的界线与删去这些点时略有出入（约 0.1% 的面积）。
- `^年份` 表示这个点从这年起才参与分区，此前不参与。用到它的有七个点：`^-280` 的下辨（2026-11-21 补，秦陇西郡属县，随陇西郡置算入秦；补它时核对过，前280 以前的疆域逐字节不变），`^-473` 的雍氏（见下一条；从前473 起是为了不动春秋卷与前475 衔接节点），`^-214` 的高阙（2026-11-22 补，前214 蒙恬取高阙，战国卷前212 节点画入秦、与秦汉卷开头接上），以及同年起参与的四个无主护点狼山北1—4（让高阙、北假两格止于狼山山脊与秦长城）；补这几个点时核对过，春秋卷与战国卷前212 以前的疆域不变。还没参与分区的点所在的格子也是描界时的护点，所以加 `^` 点后要复核衔接节点：`global/junctions.toml` 里春秋 → 战国写了 `exact = true`，两卷衔接节点的疆域不完全一致，`core/v1/registry.py` 会停下来报错。
- 文件末尾一节是 2026-11-21 为提示框与地图对上补的 9 个点（不羹、期思、桃林、河曲、应、酅、南武城、寝丘、雍氏）：这些城邑、关隘提示框里的归属合史料，地图却因描界平滑或旁边的点把它画进了邻国。在条目处补一个归属与提示框相同的点，地图随之画对（桃林塞的点挪到黄河南岸，另在北岸补河曲一点，让虢、晋的界线贴着黄河）。桃林塞（原作古魏、前661 入晋）、寝丘（原随新蔡）的提示框归属也一并按史料改正；补点的地方疆域变了几十到四千七百平方公里左右。2026-11-22 又补 2 个：南顿（顿南迁后的都城，原画在陈境里）、平丘（卫邑，前529 平丘之会的地方，原画进郑）；顿这个点挪到商水北（顿的初都），约前635 顿迁南顿，此后这个点随陈。

例：

```
少梁 110.45 35.57 梁 -641秦 -617晋 -453魏 -330秦
长平 112.92 35.8 赤狄 -594晋 -453韩 -262赵 -260秦 -257赵 -247秦
新郑 113.74 34.39 郐 -769郑 -375韩 -230秦
下阳 111.3 34.83 虢 -658晋 -453魏 ~-350
```

### 4. 与春秋图的衔接

- 两卷的 `content/seeds.txt` 完全相同；统一引擎按同一份归属点、同一张代价栅格、同一推算范围推算两卷的疆域（旧构建时山脉、手绘界河的几何与阻隔权重也须相同，由 `COST_SHA` 校验）。
- 任何一行都不在前475 这一年变更归属，所以春秋图前476 与本图前475 用的是同一组点、同一张栅格、同一份归属，算出的疆域多边形和国名位置逐字节一致。
- 两图共有的国家同键同色：颜色按政权全局 ID 定在单仓的 `global/palette.toml`。
- 原图在前350 把邹（邾）画成鲁、滕画成宋、薛画成齐。为了不动前350 以后的节点，这三个泗上小国在前351 并入所依附的大国（附庸简化，按语里有说明），它们的国都标记仍按史实年份显示。
- 改其中一张图的 `seeds.txt` 或山脉、界河时，另一张图要同步修改并一起重建。

改了 `seeds.txt` 或 `features.py` 里的时间节点、山脉、手绘河流之后，要在单仓根目录 `python run.py chunqiu zhanguo` 两卷一起重建（疆域要重算）。只改说明文字，本目录 `python run.py --html` 加上单仓根目录 `python run.py --web` 就够了。

### 6. 页面显示规则（单仓统一模板 `core/web/template.html`，本卷的设置在 `era.toml` 的 `[web]`）

- 战役、事件只显示**本期**的，即上一个节点之后（不含）到本节点（含）发生的；说明栏末尾列出“本期战役”，点击即定位。右侧列表里本期战役排在最前，其余变灰，悬停时地图上淡显。
- 长城、驰道直道、运河自修筑、开凿之年起显示；国都显示当时的国都，已废的旧都画成灰色虚线小框。
- 戎狄部族的疆域淡色、虚线边，不计入顶栏的国数。图例列本期的政权。
- 时间轴上为按年代比例的细条，下为等宽刻度；播放键下方可切换 1× / 2× 倍速。首屏为前350 节点。
- 秦统一后废弃的六国内地长城（魏、赵南、燕南、齐长城与楚方城），从前212 节点起淡显，并在名称后加“（废）”。
- 秦郡只显示当时已经设置、且郡治在秦（卫）境内的郡：郡界为虚线，郡治为圆圈加中心点（1.6 倍起画，2.3 倍起标名并写“治 某地”）。图例里可单独关掉“秦郡”，索引、对照表另列一组。
- 在索引、年表、对照表里点开一场其他时期的战役或事件，时间轴会跳到它所在的那一期。
- 缩放分级：全图只显示国名、国都、战役；放大后依次出现事件、关隘、秦郡郡治、名城（1.8 倍起画点、3.4 倍起标名）、一般城邑（灰色小点，2.6 倍起画、4.4 倍起标名）和今名。
- 只有按国一种着色；视野用下拉框切换（全域、中原、关中三晋、齐燕、楚吴越、巴蜀）。

## 七、英文版

页面里有中、英两种界面，默认中文；地图右上角「中 | EN」切换，选择记在浏览器里，网址加 `#en` 直接打开英文。英文模式下地图只标英文，悬停说明、索引、年表、对照表在英文名后附小号汉字原名；检索同时收中英文，英文不分大小写。

- **中文是源文本。** 英文按“文件 · 键 · 字段”另存在 `content/en/`：条目键为 `类别:古名`（同类同名的第二条起加 `#2`），节点键为年份，今省名为 `prov:省名`，灭国条目为 `fall:年份`。
- **指纹。** `zh.lock.json` 记下每条英文所据中文的 sha1 前 10 位。中文一改，对应英文就算“过期”；`assemble.py` 默认严格，有缺译或过期就停下，`--draft` 才放行。
- **工具。** `python tools/i18n.py status` 看缺译、过期条数；`todo` 把待译的中文导出到 `build/i18n_todo.json`；`table` 导出中英对照表 `build/i18n_table.csv`（Excel 可直接打开）供审校；`lock` 登记指纹。`names` / `notes` 参数可只看名称层或按语层。
- **译名体例**见 `content/en/GLOSSARY.md`：拼音写法、卫作 Wey、通名（Pass、Ford、Commandery、Long Wall……）、今地写法、年代写法等。

## 八、调参

疆域的推算参数不在本卷：统一引擎的通用参数在单仓 `core/engine/config.toml`，本卷的外缘、推算范围、简化容差等写在 `era.toml` 的 `[engine]`；颜色在单仓 `global/palette.toml`。本卷原来的栅格、代价、平滑与配色参数 2026-11 架构整理第三批起随旧构建一并退役。

## 九、资料与可靠程度

- **疆域归属**：依据《史记》《战国策》《竹书纪年》等史料与谭其骧《中国历史地图集》第一册战国图的大意推定，由 AI 协助编写，未逐条核对原文。战国前期（前475—前353）的归属与春秋图连续推写；随、许的灭亡年代史无明文，图上分别示意为约前360、约前390，陕北白狄入魏、陇西诸戎入秦的年份也是示意。大的格局和关键年份（如前330 魏献河西、前316 灭巴蜀、前284 乐毅破齐、前260 长平、前230—前221 秦灭六国）比较可靠；某城某年的具体归属、边缘地区（辽东、岭南、西南夷）的范围较粗略。
- **边界线**：完全是推算的示意线，只表示“这一带属于这个国家”，不代表史书里有这样一条界线。
- **秦郡**：《史记》只说“分天下以为三十六郡”，没有列出郡名。郡目与郡治主要依后晓荣《秦代政区地理》（2009）的五十四郡说，参照《汉书·地理志》《水经注》、秦封泥与岳麓书院秦简、里耶秦简；其中治所不明的新秦中、胶西、河间、巫黔四郡没有画，苍梧郡治所未详，位置为推测。统一后才析置的郡（济北、即墨、城阳、博阳、东海、河内、清河、衡山）设置年暂记为前220，只在前212 节点出现。郡界由郡治就近推算，不是史载郡界，沿海的郡界裁到海岸线为止。
- **有争议处**：地图里注明“一说”，如马陵、阏与、中牟、巨阳的地望；越国灭亡采用杨宽的约前306 说，传统说为前334/前333。
- **英文**：译名与按语由 AI 翻译，经独立复核；体例见 `content/en/GLOSSARY.md`。英文与中文不一致时以中文为准。
- **底图**：Natural Earth 1:10m（公有领域）；今省界沿用自作者此前的另一张地图。
